설명글 = 계산 방법·근거·안내 문장(잔글씨 note, 카드 부제, 항목 힌트, 빈 상태 설명 등). 데이터(이름·숫자·시술)가 아닌 글자.

**찾은 것**
1. **글자 넷 중 하나가 설명이다.** 통계·설정은 절반이 넘는다. 계산 방법을 카드마다 매번 다시 읽게 한다(통계 카드 다섯 개에 3~4줄짜리 설명).
2. **회색 글자색 자체가 읽기 기준에 못 미친다.** `--muted #8C8479`는 종이 바탕에서 3.5:1, 카드 바탕(`--soft`)에서 3.1:1(기준 4.5:1). 부제·날짜·단위가 전부 이 색이라 글자의 62%가 미달. VIP 금색 뱃지 3.3:1, 신규 초록 뱃지 4.1:1.
3. **글자가 너무 작다.** 10~11.5px가 1,500자(32%). 가장 흔한 크기가 12px.
4. **같은 말을 여러 번 한다.**
   - '○월 ○일 수집 기준'이 홈(머리말·예약 카드)·챙길 고객·방문·통계(2곳)에 되풀이된다.
   - 카르테는 '2개월 미방문 · 평소 35일 주기'를 띠와 타일 두 개에 세 번 말한다.
   - '추정'이라는 말이 카르테·통계·홈에 13번 나온다(선불 카드 하나에만 세 번).
5. **챙길 고객 카드 한 장이 화면의 40%.** 추천 문구가 늘 펼쳐져 있는데, 💬 문자 버튼이 이미 그 문구를 채워서 연다. 사유 줄은 `마지막 방문 2026-07-01 · 2개월 미방문 · 평소 35일 주기 · 뿌리염색 표준 35일`처럼 길고 겹친다.
6. **날짜가 기계 표기다.** `2026-08-02 14:00`, `마지막 2026-08-01` — 사람은 '8.2(토)', '2개월 전'으로 읽는다.

## 1. 원칙

1. **결과만 보이고, 설명은 누르면.** 계산 방법·근거 문장은 카드 제목 옆 ⓘ 안으로(접힘). 기본 화면엔 결과와 많아야 한 줄 결론.
2. **한 번 말한 건 다시 말하지 않는다.** 수집 기준은 화면 위 작은 표시 하나, '추정'은 '약'/'≈' 하나로.
3. **문장 대신 조각.** 카드 안에서 "~이에요" 문장을 쓰지 않는다. 숫자 + 짧은 라벨.
4. **날짜는 사람 말로.** 2주 안은 '어제·5일 전', 올해는 '8.2(토)', 지난해는 '25.8.2'.
5. **읽히는 최소선.** 글자 12px 이상(뱃지만 예외), 대비 4.5:1 이상.

## 3. 만들 공통 부품

- **ⓘ 설명 접기** — 카드 제목 옆 작은 ⓘ, 누르면 지금의 설명 문장이 그대로 펼쳐진다(`details`, JS 없음). 설명 내용은 지우지 않고 숨긴다 — 처음 쓰는 디자이너가 찾을 수 있게.
- **기준 표시** — 화면 위 오른쪽 '10.11 기준'. 8일 넘으면 경고색 + '수집 밀림'(지금 `isSyncStale`과 같은 기준).
- **날짜 함수 하나** — 원칙 4의 규칙. 지금 화면마다 날짜를 제각각 찍는다.
- **글자·색 토큰** — 본문 14 / 보조 12.5 / 최소 12(뱃지 11), `--muted` 새 값. 크기를 화면마다 직접 쓰지 않고 토큰으로.

## 4. 실행 순서

**P0 — 읽히게** (전 화면 한 번에, 위험 낮음 — 색과 크기만)
1. 색·글자 토큰 교체 → 대비 미달 0%, 12px 미만 5% 이하

**P1 — 설명 접기 + 반복 제거**
2. ⓘ 부품과 기준 표시를 만들고 통계·설정·홈·카르테의 설명 문단을 옮긴다. '추정' 표기 통일 → 설명글 27% → 10% 이하

**P2 — 화면별 압축**
3. 챙길 고객 카드(문구 접기·사유 한 줄)
4. 카르테 중복 정리·날짜
5. 예약 브리핑 3줄
6. 통계 '더 보기'

각 단계마다 **같은 측정으로 전후를 비교**한다(측정 도구를 저장소에 두어 다시 돌릴 수 있게).
