## 1. 할 것

### P0 숫자를 디자이너 것만 (재기 바로잡기)
- 화면 기록에 두 칸 — **운영자 폰이었나 · 홈 화면 앱으로 열었나**(참/거짓만. 이름 · 번호 · 사용자 id 는 지금처럼 없음).
- 운영자 폰 표시: 설정을 `…/settings?op=1` 로 한 번 열면 그 폰에만 저장된다(`?op=0` 이면 해제). 디자이너 화면엔 아무것도 생기지 않는다.
- 마이그레이션 `0025`(감시 함수만 바꾼다): 매장별 **디자이너 화면 수(운영자 폰 뺌) · 앱으로 연 비율 · 운영자 폰 화면 수(따로)** + **기록 시작일**. 화면 속도는 지금처럼 모두 센다(지금 속도 표본은 대부분 운영자 폰이다).
- 감시 출력 예: 맨 위 `화면 기록 10.15부터`, 매장마다 `hayewoni  디자이너 화면 12번(앱 80%) · 연락 0명 · 마지막 사용 오늘 · 운영자 폰 35번`. `0025` 전에도 감시는 지금 출력 그대로(깨지지 않음).

### P1 이번 주 새로 오른 분부터
- 챙길 고객에 **'새로'** — 지난주 수집 땐 목록에 없었는데 이번 수집에 오른 분: 재방문 주기를 이번 주에 넘긴 분(휴가 반영 — 지금 판정과 같은 규칙) · 이번 주 첫 방문 · 연락 뒤 숨김(14일)이 이번 주에 끝난 분.
- 머리말 '챙길 고객 84명 · **이번 주 새로 12명**', 새로 오른 분을 맨 위에 모으고 '새' 표시. 그 아래는 지금 순서 그대로.
- 홈 '챙길 고객' 알약에도 '새로 N' — 360px 에서 안 들어가면 챙길 고객 화면에만.
- 판정은 `lib/customers` 한 곳. 다음에 주간 알림(v6 P2)을 하면 '새로 N명'도 같은 숫자를 쓴다.

### P2 (v7 P1) 덜 받기 — 금요일 '고치기 전' 숫자 뒤 (예정대로)
- 통계 거래 2년만 · 추천 시술 근거 저장 · 챙길 고객 겹쳐 받기. 가장 느린 통계(1.1초) · 앱 처음 열기(느린 때 1.9초)가 대상.

### P3 다시 열게 — 설치 안내 · 주간 알림 (다음 주, P0 숫자 뒤)
- 디자이너 화면 수 · 앱으로 연 비율 · 연락 수가 한 주 쌓이면 정한다.
  - 앱으로 연 비율이 낮으면 → **홈 화면에 추가 안내**(한 번, 닫으면 다시 안 뜸. 아이폰은 공유 → '홈 화면에 추가', 안드로이드는 설치 버튼).
  - 한 주 넘게 안 여는 매장이 있으면 → **주간 알림**(v6 P2 그대로 — 수집 뒤 첫 영업일 아침 '이번 주 챙길 고객 84명 · 새로 12명', 손님 정보 없음, 디자이너가 켠다).
  - 연락이 꾸준하면 → 내 말투로(v6 P3).

## 2. 하지 않을 것
- **사람 단위로 재기** — 사용 수는 매장 단위 숫자만. 누가 언제 무엇을 열었는지(사용자 id)는 남기지 않는다.
- **챙길 고객 기준을 바꿔 숫자 줄이기** — 84명은 그대로 두고 '어디서부터'를 보여 준다.
- **디자이너에게 사용을 재촉** — 감시 숫자는 운영자만 본다.
