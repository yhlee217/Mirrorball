## 1. 할 것

### P0 기본기 — 작고, 매일 체감된다

- **0-1 챙길 고객을 끝까지** — 50명 다음에 '더 보기'(50명씩). 머리말 숫자와 목록이 같은 사람을 가리키게 한다.
- **0-2 누르는 영역 44px** — `?` · ⚙ · ‹ 홈 · 잔액 차감 · 홈케어 팁 표식 · 제안 칩. 보이는 크기는 그대로 두고 누르는 영역만 넓힌다. UI 측정(`run.sh --check`)에 '24px 미만 0곳'을 목표로 더한다.
- **0-3 덜 기다리게** — (가) 1,000건씩 나눠 받는 것을 차례로 → 한꺼번에(`fetchAllRows`, 모든 화면에 듣는다). (나) 고객 목록은 '시술' 필터를 열 때만 손님별 시술 갈래를 받는다. (다) 카르테는 (가)만으로 충분한지 보고, 모자라면 '권할 것' 근거를 수집 때 한 번 계산해 둔다.

### P1 첫 방문 손님 챙기기 — 이번 계획의 중심

챙길 고객에 **'첫 방문'**을 더한다. 두 순간이 있다.

| | 언제 | 문구(예) | 왜 |
|---|---|---|---|
| **(가) 안부** | 첫 방문이 수집에 잡힌 뒤 ~ 첫 방문 14일까지 | "○○님, 지난주 뿌리염색 해드린 하예원이에요 😊 지내보시니 괜찮으세요? 염색 당일은 두피 자극을 피하고… 불편한 점 있으면 편하게 말씀 주세요!" | 예약 권유 없이 안부 + 그날 시술의 홈케어 팁 한 줄. 처음 온 손님이 '나를 기억한다'고 느끼는 첫 접점. 수집이 일요일이라 '지난주'가 자연스럽다 |
| **(나) 다시 오실 때** | 그 시술의 표준 주기가 지나면 — 뿌리염색 5주 · 남자커트 4주 · 여자커트 8주 · 펌 13주 (`lib/care-cycle.ts`) | 지금 재방문 문구와 같은 결 | 지금은 이 시점에 아무것도 안 뜬다 |

- 둘 다 예약했으면 빼고, 연락하면 14일 쉬고(지금 규칙), 설정의 이탈 기준(6개월에 3회 미만 등)에 걸리면 뺀다.
- 뱃지는 **'첫 방문'**(초록) — 이탈 위험 · 재방문 도래와 같은 자리. 홈의 '챙길 고객 N'에 함께 세고, 이탈위험 · 재방문도래 숫자(2회 이상 손님)는 그대로 둔다.
- 판정은 웹에서 한다 — 워커·맥미니를 다시 깔 필요가 없다. 점검 스크립트(`ux_probe`)도 같은 규칙으로 맞추고 테스트로 대조한다(휴가 반영 때와 같은 방식).
- 규모(어림): 안부는 디자이너당 주 3~5명(월 신규 약 16명). (나)는 켜는 첫 주에 지난 손님이 한꺼번에 오를 수 있다 — 숫자는 §3 측정으로 정한다.

### P2 연락 효과 — 보낸 뒤 오셨나

- 챙길 고객 맨 위 한 줄: **'지난 4주 연락 32명 → 11명 오심 · 4명 예약'**(셈법은 `?` 안에). 첫 방문 안부 · 재방문 · 이탈 위험별로는 통계 '더 보기'.
- 셈법: 연락한 날 뒤의 방문(수집되면 잡혀서 최대 1주 늦다) 또는 지금 잡혀 있는 예약. 연락 기록은 10.12부터 쌓이므로 **4주쯤 뒤**부터 의미가 있다 — 그 전엔 '쌓이는 중'.
- 통계 '신규 재방문(90일)'에 '안부 보낸 분 / 안 보낸 분'을 나눠 본다 — 안부가 실제로 두 번째 방문을 늘리는지 3개월 뒤에 확인한다.

### P3 내 말투로 (선택)

- 설정에 '문구' 카드 — 종류별(안부 · 다시 오실 때 · 재방문 · 오랜만) 틀을 디자이너가 고친다. {이름} · {시술} · {기간} · {팁}을 끼우고 미리보기. 지금은 세 디자이너가 같은 문구를 쓰고, 말투가 안 맞으면 매번 문자 앱에서 고쳐야 한다.

## 2. 하지 않을 것

- **수집을 더 자주** — HandSOS 약관 리스크로 주 1회를 유지한다(`LAUNCH.md`). '언제 기준'을 밝히는 건 v3에서 했다.
- **자동 발송** — 문자는 늘 디자이너 손에서. 앱은 문구를 채워 문자 앱을 열 뿐이다.
- **생일 · 유입 경로** — 지금 수집 범위 밖이다. 더 긁어야 해서 약관 리스크가 커진다.
- **근황을 문구에 자동으로** — 메모 정리(AI)가 틀릴 수 있어 손님께 그대로 나가면 안 된다.

## 3. 시작 전에 잴 것 (추측하지 않는다)

`worker/retention_probe.py` — 읽기 전용, 날짜와 건수만 센다(이름·전화번호는 읽지 않는다). 맥에서 한 번:

```bash
cd ~/Dev/Mirrorball && git pull origin claude/charming-planck-hmgazi && .venv/bin/python worker/retention_probe.py
```

|---|---|
| 첫 방문 → 두 번째 방문까지 걸린 날(중앙값·사분위) · 28/42/56/90일 안에 다시 오신 비율 | (나)의 시점 — 표준 주기가 실제보다 늦으면 앞당긴다 |

| 방문 1회 · 예약 없는 손님(첫 방문 뒤 0~13 · 14~27 · 28~56 · 57~90 · 91~180일) | (나)를 켜는 첫 주에 몇 명이 한꺼번에 오르나 — 많으면 처음엔 최근 90일만 |
| 연락 기록과 그 뒤 방문 · 예약 | P2 기준선 |

## 5. 정해야 할 것

1. 첫 방문 안부 — **넣는다(추천)** / 넣지 않는다
2. 안부 문구 — **안부 + 홈케어 팁만, 예약 권유 없이(추천)** / 예약 권유도 넣는다
3. '다시 오실 때' 시점 — **시술 표준 주기로 시작해 측정 뒤 조정(추천)** / 측정한 중앙값으로
4. 연락 효과를 보여줄 곳 — **챙길 고객 맨 위 한 줄 + 통계 '더 보기'(추천)** / 통계에만
5. 내 말투로(P3) — **이번엔 빼고 P2 결과(문자 버튼을 얼마나 쓰나)를 본 뒤 정한다(추천)** / 이번에 함께
