# 실행 문서 ② — 무료 경쟁 진단 영업 (콜드 아웃리치)

> `compete.py` 결과 한 장을 훅으로, 잠재 디자이너에게 1:1로 다가가
> 무료 진단 → Basic 제작으로 전환한다. **개인화가 생명, 대량 발송 금지.**

## 1. 타깃 선정 (주 50명 목표)

인스타그램에서 추린다:
- **검색**: `#강남발레아주` `#강남역펌` `#한남동헤어` 등 *지역+시술* 해시태그
- **기준**: ① 팔로워 1천~3만(개인 디자이너 규모) ② 최근 2주 내 게시(활동성) ③ 예약 링크/프로필 미흡(개선 여지)
- 스프레드시트에 `핸들 / 지역 / 주력시술 / 메모` 기록

## 2. 진단 실행

각 타깃의 지역·시술로 `targets/{handle}.yaml` 만들고:

```bash
python compete.py targets/{handle}.yaml      # → compete.md (경쟁 노출 + 대상 0회 여부)
```

- 비용 관리: 무료 티어(Gemini) 한 엔진으로, sampling=1, 질문 3~4개면 충분. (대량 진단의 원가 통제)
- 결과에서 **"대상 0회 + 경쟁 N곳 노출"**이 나오는 디자이너가 1순위 타깃.

## 3. 메시지 (개인화 필수)

**1차 DM** (관심 끌기 — 팔지 않기):
> 안녕하세요 원장님 :) {지역} {시술} 검색하다 작업 보고 연락드려요.
> 요즘 손님들이 ChatGPT·Gemini한테 "{지역} {시술} 잘하는 곳" 물어보는데,
> 거기서 원장님이 아직 한 번도 안 나오시더라고요. (대신 {경쟁매장}이 나와요)
> 무료로 어디서·왜 안 나오는지 정리한 거 보여드려도 될까요? 부담 안 가지셔도 돼요.

**응답 오면** (자료 전달 + 미팅):
> 보내드릴게요! [compete.md 캡처/링크]
> 이건 현재 상태고, 보통 3주면 바뀝니다. 어떻게 만드는지 5분만 통화로 설명드릴까요?

**무응답 시 1회만 팔로업** (3~4일 뒤, 그 후 중단):
> 원장님, 지난번 자료 혹시 보셨어요? 안 궁금하시면 더 안 보낼게요 :)

> ⚠️ **금지**: 복붙 티 나는 대량 발송, 하루 과다 발송(계정 제한·스팸 인상), 첫 메시지부터 가격 들이밀기.

## 4. 전환 흐름

```
DM(1차) → 응답 → 무료 진단 자료 → 5분 통화 → Basic 제작(15만) → 1달 뒤 Pro 전환
```

## 5. KPI (주 단위로 추적)

| 지표 | 목표(시작) | 비고 |
|---|---|---|
| 발송 | 주 30~50건 | 계정 안전 범위 내 |
| 응답률 | 15~25% | 개인화·훅 품질의 척도 |
| 통화 전환 | 응답의 30%+ | |
| 제작 계약 | 주 1~3건 | 여기서 매출 시작 |

- 응답률이 낮으면 → **타깃 기준**(개선 여지 큰 디자이너)과 **훅 문구**를 먼저 손본다.
- 제작 전환이 낮으면 → 통화에서 **무료 진단의 손실**을 더 구체적으로 보여준다.

## 6. 다음 단계 연결

- 만족한 제작 고객 → **소개 요청(⑤)** + 리퍼럴 카드.
- 한 살롱에서 2명 이상 반응 → **원장에게 살롱 패키지 제안(③)** → `salon_b2b2c.md`.
