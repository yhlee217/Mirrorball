## 1. 할 것

### P0 새 디자이너 첫 로그인 — 메일이 안 와도 들어오게
- **맥에서 코드 한 줄** — `worker/login_code.py 이메일 매장`:
  - 계정이 없으면 만든다(메일 확인된 상태로).
  - 매장에 잇는다. `link_designer` 와 같은 규칙으로 — 데모 소속은 그대로 두고, 이미 다른 실제 매장에 이어진 계정은 `MULTI=1` 이 있어야 잇는다.
  - 앱 로그인 코드(6자리)를 **화면에만** 찍는다.
  - 미리보기가 기본이고, `CONFIRM=1` 을 붙이면 실행한다. 코드는 한 번만 쓸 수 있고 1시간 동안 유효하다(Supabase 설정값).
  - 운영자가 코드를 전화나 카톡으로 불러 주면, 디자이너님은 앱에서 '코드를 이미 받았다면 입력하기'로 넣는다. 그러면 바로 자기 매장이 열린다('아직 연결되지 않았어요' 단계를 거치지 않는다).
- **로그인 화면을 한국어로**:
  - 보내기 실패(팀원 주소가 아님 · 너무 잦음 · 주소 오류)와 코드 실패(틀림 · 시간 지남)를 알아들을 수 있는 말로 바꾸고, "운영자에게 코드를 받아 아래에 넣어 주세요"를 붙인다.
  - 코드 단계에 '메일이 안 오면 스팸함을 보거나, 운영자에게 코드를 받아 넣어도 돼요' 한 줄을 넣는다. `/start` ②에도 같은 한 줄.
- **메일 양식 두 개를 저장소에** — `supabase/email_templates/` 에 가입 확인 · 로그인 양식을 둔다. 한국어이고, 6자리 코드만 담는다. 링크는 넣지 않는다 — 아이폰에서 링크를 누르면 홈 화면 앱이 아니라 사파리에서 로그인되기 때문이다. 메일 설정(SMTP)을 하게 되면 그때 붙여 넣으면 된다(키가 아니라 문구다).
- 안내서 §2 를 새 순서로 고친다 — 메일이 되면 지금처럼, 안 되면 코드 한 줄로.

### P1 맥이 없어져도 — 열쇠 한 부와 되살리는 순서
- **열쇠 한 부를 비밀번호 관리자에**(운영자) — `MIRRORBALL_KEK` 값을 아이폰 '암호' 앱이나 1Password 같은 곳에 한 부 둔다.
  - 채팅 · 문서 · 메신저엔 여전히 붙여 넣지 않는다. 비밀번호 관리자만 예외다.
  - HandSOS 접속 정보와 매장 열쇠는 이 열쇠로 감싸서 DB 에 있다. 그래서 이 열쇠 하나만 있으면 새 맥에서 모두 되살아난다.
- **맞게 적었는지 확인하는 도구** — `worker/kek_check.py`:
  - 지금 열쇠로 매장마다 열쇠(DEK)가 풀리는지 본다.
  - 비밀번호 관리자에 적은 값을 붙여 넣으면(화면에 안 보이게) 같은지만 말해 준다. 열쇠 값은 어디에도 찍지 않는다.
- **백업을 쓰자마자 다시 읽기** — 일요일 백업이 파일을 쓴 뒤 바로 다시 열어, 지금 열쇠로 풀리는지와 담긴 수가 같은지 확인하고 운영 기록에 남긴다.
- 안내서 §6 에 '맥이 고장 나거나 없어지면' 순서를 더한다. 새 맥에 저장소 받기 → `.env.local` 을 비밀번호 관리자 값으로 채우기 → `kek_check` → 수집 한 번 → 일요일 자동 실행(launchd) 다시 걸기. Cloudflare · GitHub 는 손대지 않는다.

### P2 운영 숫자 문단속
- **`0027_ops_lock.sql`** — 운영 숫자 함수 다섯이 **운영자 계정**이거나 **감시 열쇠**가 있을 때만 숫자를 준다. 둘 다 없으면 오류.
  - 감시 열쇠: SQL 한 줄(`select ops_new_watch_key();`)이 무작위로 만들어 한 번만 보여 준다. DB 엔 해시만 남는다. 이 값을 GitHub 비밀값 `OPS_WATCH_KEY` 에 넣는다. 서비스 키가 아니라 운영 숫자만 여는 열쇠다.
  - 운영자 계정: `select ops_add_reader('운영자 이메일');` 한 줄. `/ops` 는 쿠키 대신 이 계정일 때만 열린다(설정의 '운영 숫자' 버튼도). 운영자 폰 표시(`?op=1`)는 지금처럼 '사용 수에서 빼기'에만 쓴다.
- 코드는 SQL 을 실행하기 전에도 지금처럼 돈다. 매일 감시는 열쇠가 있으면 넘기고 옛 함수면 그대로 부른다. `/ops` 는 0027 전엔 지금처럼 쿠키로 연다.
- 다른 디자이너 계정 · 데모 계정 · 공개 키만으로는 다섯 함수 모두 거절된다(임시 Postgres 로 확인).

## 2. 하지 않을 것
- **비밀번호 로그인** — 디자이너님이 외울 것이 하나 더 생기고, 잊으면 결국 운영자가 바꿔 줘야 한다. 코드 한 줄이 같은 일을 더 적은 품으로 한다.
- **앱 화면에서 코드 발급** — 서비스 키가 필요한 일이라 맥에서만 한다(v13 에서 '앱 화면에서 디자이너 연결'을 하지 않은 것과 같은 이유).
- **백업을 클라우드 드라이브로** — 백업엔 손님 메모가 담겨 있어서 새 보관처(국외 이전)가 생긴다. 원본은 DB 이고, 열쇠만 있으면 새 맥에서 다음 일요일부터 다시 쌓인다.
- **감시에 서비스 키** — v13 에서 정한 대로 두지 않는다. 감시 열쇠는 운영 숫자만 연다.
- **액션을 최신 큰 판(v7)으로 한꺼번에** — 바뀐 점을 다 확인하지 못했다.
