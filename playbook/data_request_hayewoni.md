# 하예원 원장님께 — 추가로 주시면 좋은 자료

> 보내주신 소개·전문시술·FAQ 덕분에 **프로필 페이지는 이미 발행 준비가 됐습니다.** 🙏
> 아래는 *남은 빈칸*과 *새로 추가된 기능(원장 앱)*에 필요한 것만 모았습니다.
> **모르거나 지금 없는 칸은 비워두셔도 됩니다** — 그 부분만 빼고 나머지는 그대로 진행돼요.
> (전체 항목·다른 디자이너용 양식은 `playbook/data_request.md` 참고)

---

## ✅ 이미 받은 것 (다시 안 주셔도 됩니다)
소개 문구 · 전문 시술 4종(레이어드컷·뿌리펌·레이어드펌·퍼스널이미지컨설팅) · 경력 · FAQ 7개 · 오시는 길.

---

## 1. 프로필 마무리 — 빈칸 3개만

```yaml
booking_url: "[네이버 예약 URL — 손님이 바로 예약 누를 링크]"
photo_url:   "[프로필 사진 URL 또는 사진 1장 첨부 — 없으면 이니셜로 나갑니다]"
address:     "서울 용산구 한남동 [상세주소 — 건물명·층까지]"
```
> 이 셋이 채워지면 "예약 버튼·얼굴 사진·지도 정확도"가 완성됩니다.

---

## 2. 손님이 AI에 물을 질문 10개 — *AI 노출 진단용*

손님이 ChatGPT·Gemini에 **실제로 칠 법한 문장 그대로**. (제가 지어내지 않고 원장님 감각으로 정하는 게 정확합니다.)

```yaml
questions:
  - "한남동 레이어드컷 잘하는 미용실 추천해줘"
  - "이태원 근처 뿌리펌 잘하는 디자이너 알려줘"
  - "퍼스널컬러까지 봐주는 미용실 어디가 좋아"
  # ... 위 톤으로 10개 내외 (지역·시술·고민 조합)
```

---

## 3. 단골 고객 카르테 5~10명 — *원장 앱·"오늘 챙길 고객" 알림용* ★새 기능

> 예약이 잡히면 **그 손님의 지난 시술·대화·취향을 자동으로 띄워주고**, 생일·리터치 시기가 되면 **"오늘 챙길 고객"으로 알려드리는** 기능입니다.
> ⚠️ **자동 발송은 안 합니다.** 시스템은 *누구를·왜·추천 문구 초안*까지만, **보내는 건 원장님이 직접**. (손님은 "내 디자이너가 직접 챙겼다"고 느낍니다.)
> 🔒 **연락처는 원장님 폰에만** — 웹·발행물엔 절대 안 올라갑니다.
> 엑셀·메모·카톡 캡처 **아무 형식이나** 주시면 제가 정리합니다. 아래는 1명 예시:

```yaml
id: jiwoo
name: "지우"
contact: "010-xxxx-xxxx"          # 원장님 직접 연락용 (비공개)
birthday: "11-04"                  # 생일 챙김 (연도 불필요)
first_visit: "2026-01-18"
prefer: ["어깨 길이 유지", "자연스러운 컬"]
care_cycle_days: 150               # 펌 리터치 주기(일). 발레아주 70 / 컬러 90 정도
loyalty_visits: 4
booking:                           # 다가오는 예약 있으면
  date: "2026-06-18"
  time: "14:00"
  service: "레이어드펌"
history:                           # 최근 시술부터
  - date: "2026-04-02"
    service: "레이어드펌"
    notes: "결 매끄럽게, 손질 편하게 원함"
  - date: "2026-01-15"
    service: "발레아주(8레벨)"
    notes: "밝은 톤 선호, 뿌리 티 안 나게"
```

> **꼭 필요한 칸만 꼽으면**: 성함 · 생일 · 마지막 시술 날짜 · 시술명 · (있으면) 대화 메모.
> 나머지(주기·예약·선호)는 있으면 더 똑똑해지고, 없어도 됩니다.

## 4. (선택) 더 풍성하게 — 있으면 좋고 없어도 됩니다

| 주시면 | 나오는 것 |
|---|---|
| **메뉴·가격·소요시간** (시술별) | 프로필 메뉴판 |
| **후기 3~5개** (별점·내용·작성자) | 프로필 후기 위젯(평점 자동) |
| **전후 사진 쌍** (before/after) | 드래그 비교 갤러리 |
| **"이게 잘 쓴 소개글" 샘플** 1~2개 | 카피 자동 생성 품질 기준 |
| **잘 통했던 멘트·상담법** 몇 개 | "잘 파는 카피" 엔진 학습 |

---

### 보내실 때
- 형식 신경 안 쓰셔도 됩니다 — **텍스트·엑셀·캡처 아무거나** 편하신 대로.
- **우선순위**: 1번(빈칸 3개) → 2번(질문 10개) → 3번(단골 5명). 여기까지면 프로필+진단+원장 앱이 다 돌아갑니다.
- 모르는 칸은 비워두세요. 경고만 뜨고 나머지는 진행됩니다.
