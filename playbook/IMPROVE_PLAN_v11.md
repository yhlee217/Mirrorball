## 1. 할 것

### P0 처음 들어오는 길
- **매장 없는 계정 화면**: "이 계정(○○@…)은 아직 매장에 연결되지 않았어요 — 운영자에게 이 이메일을 알려 주세요" + [다시 확인] · [다른 이메일로 로그인]. 데모는 아래에 작게 '데모로 둘러보기(실제 매장 아님)'.
- **실제 매장이 먼저**: 소속이 여럿이면 데모 매장(`demo-…`)은 뒤로 — 데모를 먼저 만들었어도 실제 매장이 연결되면 실제 매장이 열린다. 그 밖엔 지금처럼 가장 먼저 소속된 매장.
- **시작 안내 페이지** `/start` — 로그인 없이 열린다(손님 정보 없음). ① 로그인(이메일 → 메일로 온 6자리 코드) ② 홈 화면에 추가(아이폰: 사파리 공유 → '홈 화면에 추가', 안드로이드: 크롬 ⋮ → '홈 화면에 추가') ③ 매주 할 일(월요일 챙길 고객 '새로'부터 · 방문 탭에서 노쇼 · 방문 뒤 문자). 운영자는 주소 하나만 카톡으로 보내면 된다. 설정 맨 아래에 '사용 안내 ›'.

### P1 손에 익은 연락 수단 — 카톡 등으로 보내기
- 챙길 고객 펼친 곳의 '문구 복사'를 **'카톡 등으로 보내기'**로 — 폰의 공유 창이 문구가 채워진 채 열리고, 카카오톡 · 문자 · 다른 앱을 고른다(공유 창에 '복사'도 있다. 공유가 안 되는 브라우저는 지금처럼 복사). 보내기를 마쳐야 '연락함'(수단 '공유') — 취소하면 안 남는다.
- **설정 '연락 버튼'**: 문자(지금) / 카톡 등 — 고르면 줄의 큰 버튼이 💬 문자 ↔ 📤 보내기로 바뀐다. 번호가 없는 분은 늘 보내기(지금의 복사 자리).
- 방문 탭 '방문 뒤 문자'도 같은 설정을 따른다(이건 연락 기록에 안 남는다 — v9 그대로).
- 사용 현황 점검(`usage_probe`) · 매일 감시의 연락 수에 '공유'도 센다(지금도 손님 수로 세므로 숫자는 자동으로 들어온다).

## 2. 하지 않을 것
- **카톡으로 자동 발송 · 카톡 채널 연동** — 문자는 늘 디자이너 손에서. 손님 카톡 친구 목록도 앱이 보지 않는다(공유 창은 폰이 띄운다).
- **새 이메일 가입 막기** — 막으면 운영자가 계정을 먼저 만들어 줘야 한다(지금의 '로그인 → 매장 연결' 순서가 바뀐다). 대신 1 · 2로 함정만 없앤다.
- **데모 없애기** — 매장 소개(영업) 때 쓸 수 있다. 실제 매장이 늘 먼저면 해가 없다.

## 4. 정해야 할 것

1. 매장 없는 계정 · 데모(P0) — **안내 화면 + 데모는 작게 + 실제 매장이 먼저(추천)** / 데모 버튼 없애기
2. 시작 안내(P0) — **로그인 없이 여는 `/start`(추천 — 운영자가 주소만 보낸다)** / 로그인 뒤 앱 안에만
3. 연락 수단(P1) — **'문구 복사' 자리를 '카톡 등으로 보내기'로 + 설정에서 큰 버튼 고르기(추천)** / 공유 버튼만 더하기
4. 큰 버튼 기본값 — **지금처럼 문자(추천 — 디자이너님 답을 듣고 매장별로 바꾼다)** / 카톡 등
