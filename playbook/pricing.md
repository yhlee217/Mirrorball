# 실행 문서 ① — 가격 티어 (구독 상품화)

> 일회성 제작비를 **월 반복 매출(MRR)**로 바꾸는 4단 구조.
> 숫자는 프리미엄 니치(미용사) 기준 시작점 — 시장 반응 보며 조정.

## 상품 구조

| 단계 | 이름 | 가격 | 포함 | 대상 |
|---|---|---|---|---|
| 0 | **무료 경쟁 진단** | 0원 | `compete.py` 1회 + 결과 리포트 1장 | 모든 잠재 고객 (영업 훅) |
| 1 | **Basic — 제작** | **15만원 (1회)** | 프로필 제작·발행 + 카드 3종 1회 + 발행 후 1개월 노출 모니터링 | "일단 간판부터" |
| 2 | **Pro — 구독** | **월 4만원** (연납 40만원) | 분기 재진단+전후 리포트 / 월 인용 콘텐츠 2건 / 카드 무제한 / 프로필 수정 | 꾸준히 관리받고 싶은 디자이너 |
| 3 | **Premium — 대행** | **월 15만원** | Pro 전체 + 콘텐츠 실제 발행 대행 + 후기 수집 + 예약 세팅 | 마케팅 통째 위임 (소수) |

## 전환 경로 (Funnel)

```
무료 진단(0)  →  Basic 제작(15만)  →  Pro 구독(월 4만)  →  Premium(월 15만)
   영업 훅          첫 결제·신뢰        반복 매출 핵심        객단가 극대화
```

- **무료 진단**은 손실(경쟁이 내 손님 가져감)을 보여줘 Basic 결제로 연결.
- **Basic 발행 후 1개월** 무료 모니터링이 끝나는 시점에 → *"계속 관리받으실래요?"* 로 **Pro 자연 전환**.
- Pro에서 콘텐츠 발행을 귀찮아하는 고객 → **Premium 업셀**.

## 왜 이 숫자인가 (마진 감각)

- **원가 핵심은 API 비용**: 진단 1회(질문 10 × 엔진 3 × 샘플 2 = 60콜)도 무료 티어(Gemini)·소액. Pro의 분기 진단·월 콘텐츠도 **콜당 원가는 수십~수백 원** 수준 → 마진은 거의 시간(노동).
- 즉 **1인 운영자의 병목은 돈이 아니라 시간** → 자동화된 Basic/Pro는 마진이 높고, 시간 드는 Premium은 소수 고가로 제한.

## 운영 규칙

- **연납 할인**: Pro 월 4만 → 연 40만(2개월치 무료) 로 현금흐름·락인 확보.
- **살롱 할인**: 같은 살롱 3명 이상 Basic 동시 → 1인당 12만 (B2B2C 연계, → `salon_b2b2c.md`).
- **이탈(churn) 방지**: Pro 가치는 *"매달 눈에 보이는 변화"*. 매달 `compare.py` 리포트를 **먼저 보내주면** 해지가 줄어든다. (가치를 증명한 뒤 청구)
- **환불·성과 옵션**은 별도 상품(#2 성과 연동 과금)으로 분리해 Basic/Pro는 단순하게 유지.

## 목표 감각 (예시)

| 시나리오 | 계산 | 월 매출 |
|---|---|---|
| Pro 30명 | 30 × 4만 | **120만** |
| Pro 30 + Premium 5 | 120만 + 5×15만 | **195만** |
| + Basic 신규 월 4건 | + 4×15만(일회) | +60만 (변동) |

→ **Pro 구독자 수가 곧 안정 매출.** 그래서 "획득(④) → Pro 전환(①)"이 1순위.
