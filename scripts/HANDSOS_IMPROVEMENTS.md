## ① 고객 아이덴티티·병합 키 정비 ✅

**문제**: 카드 분열(custno 유/무 방문), 메모/금액 수정 시 이중집계, 익명 동일거래 붕괴, custno "0" 소실.

**구현** (`import_handsos.py`):
- `merge_records` 를 **(날짜·고객·시술) 그룹 교체** 방식으로 재설계 — 새 스크랩이 같은 방문
  그룹을 다시 가져오면 그룹째 교체(최신이 진실). 메모/금액 수정 = 갱신 1건. 새 스크랩 범위
  밖 날짜는 유지(400일 누적 그대로). 같은 방문 동일시술 2건(금액 다름)도 보존.
- `_reconcile`: custno 없는 방문 묶음(np:)이 **이름+전화 정확 일치**하는 no: 카드와 병합.
  동명이인(전화 다름)은 병합 안 함. 병합 내역 로그.
- `write_out`: 화해 시 옛 np 카드 파일의 **수동 필드(메모·관계 등) 승계** 후 고아 파일 정리.
- `_custno`: 전부-0 고객번호("0", "000") 빈값化 방지.

**테스트 7**: 그룹 교체/유지/보존, 화해 병합/동명이인 스킵/수동 승계+고아 정리, 익명 보존, custno 0.

# 음성녹음 접근 기능 검토 (앱)

**요청**: 앱이 사용자 휴대폰의 음성녹음에 접근을 요청하고 참고할 수 있는 기능.

## 결론 먼저

| 방식 | 가능? | 비고 |
|---|---|---|
| 폰의 **기존 녹음앱 파일에 자동 접근** | ❌ **불가** | iOS/Android 샌드박스 — 웹(PWA)은 물론 네이티브 앱도 타 앱(음성메모) 저장소를 직접 못 읽음 |
| **앱 안에서 녹음**(마이크 권한 요청) | ✅ 가능 | MediaRecorder + getUserMedia — 권한 팝업 1회, PWA 에서 동작(iOS 포함) |
| **파일 선택/공유로 기존 녹음 가져오기** | ✅ 가능 | `<input type=file accept="audio/*">` 또는 공유시트 — 사용자가 골라주는 방식 |
| 브라우저 안 **STT(음성→텍스트)** | ⚠️ 제한적 | Web Speech API 는 iOS PWA 에서 불안정 — 신뢰 불가 |
| **기존 voicenote 파이프라인** 활용 | ✅ **이미 구축됨** | `voicenote.py`: 녹음 → Whisper(무료 STT) → Claude 요약 → **고객 매칭 → 카르테 자동 기입** |

핵심 정정: "폰에 있는 음성녹음에 (자동으로) 접근"은 어떤 기술로도 안 된다.
가능한 것은 ①앱 내 녹음, ②사용자가 골라서 넘기기, ③공유 폴더 경유 자동 처리(이미 있음).

## 권장 설계 — 2단계

**Phase 1 (즉시, 개발 거의 0): 기존 voicenote 파이프라인 운영 개시**
```
디자이너: 폰 기본 녹음앱으로 녹음(첫마디에 고객 이름) → 클라우드 폴더에 공유
컨시어지 머신: voicenote.py watch → Whisper 변환 → Claude 요약 → 고객 매칭 → 카르테 메모 기입 → 앱 재빌드
디자이너: 다음날 앱에서 그 고객 카드에 메모가 "참고"로 이미 붙어 있음
```
- 이미 구현돼 있고(`voicenote.py process/watch/apply`), 앱 쪽 "참고"는 고객 메모/이력으로 자연 노출.
- 권한 팝업·브라우저 제약과 무관. done-for-you 모델과 정확히 일치.

**Phase 2 (선택, 앱 개발): 고객 화면 '음성 메모' 버튼**
- 고객 상세에 🎤 버튼 → **마이크 권한 요청** → MediaRecorder 로 녹음 → 로컬 저장(IndexedDB)
  \+ "보내기"(공유시트/다운로드 → 동기화 폴더) → Phase 1 파이프라인 합류.
- \+ 파일 선택 버튼(기존 녹음 가져오기). STT 는 브라우저에서 하지 않음(신뢰 불가) — 파이프라인이 담당.

## 프라이버시·법률 유의점 (중요)

- **녹음엔 고객 PII·민감정보**가 들어감 → 기존 원칙 그대로: 로컬 전용, `clients/` git 제외,
  전사 텍스트도 `_redact_pii` 경로로 전화번호 마스킹.
- **대화 녹음의 법적 경계(한국)**: 본인이 참여한 대화 녹음은 통신비밀보호법상 합법이지만,
  **제3자 간 대화 녹음은 불법**. 시술 중 상담 메모 용도로 본인-고객 대화만. 고객 안내(동의)
  문구를 두는 게 신뢰·분쟁 예방 측면에서 권장.
- 마이크 권한은 **눌렀을 때만 요청**(첫 진입에 요구하면 거부율↑, 스토어/브라우저 정책에도 부합).
