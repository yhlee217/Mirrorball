인스타그램 Graph API 셋업 안내서

살롱 기존 인스타 계정으로 토큰을 발급해 모니터링을 켠다. 새 계정 안 만듦 · 전부 무료.
⏱ 약 40~60분 (대부분 1회성) 💸 비용 0원 🔒 유령계정 아님 · 밴 위험 없음
준비물 — 살롱 인스타 계정 · 페이스북 계정(없으면 무료 생성) · PC 브라우저
※ Meta 화면·메뉴 이름은 수시로 바뀝니다. 이름이 다르면 비슷한 항목을 찾으면 돼요.

1 인스타를 '비즈니스 계정'으로 전환 폰 · 5분

  1. 인스타 앱 → 내 프로필 → 우상단 ☰ 메뉴 → 설정 및 개인정보
  2. 계정 유형 및 도구 → 프로페셔널 계정으로 전환
  3. 카테고리 미용실/헤어살롱 선택 → 비즈니스(Business) 선택 (크리에이터도 되지만 살롱은 비즈니스 권장)
  4. 완료. 게시물·팔로워 그대로, 언제든 개인계정으로 되돌릴 수 있어요.
이미 비즈니스/크리에이터면 이 단계는 건너뛰세요.

2 페이스북 페이지 연결 10분

Graph API는 보통 인스타 비즈니스 계정 ↔ 페이스북 페이지 연결을 요구해요.

  1. 페이지가 없으면 생성: facebook.com/pages/create → 살롱 이름으로(무료)
  2. 인스타에 연결: 인스타 앱 → 설정 → 계정 센터(Account Center) → 계정 연결 → 페이스북 페이지 연결
    또는 Meta Business Suite(business.facebook.com)에서 인스타·페이지를 한 비즈니스에 묶기
  3. 확인: Meta Business Suite에 인스타 계정과 페이지가 같이 보이면 OK

3 Meta 개발자 앱 만들기 10분

  1. developers.facebook.com → 로그인(살롱 페북) → 최초면 개발자 등록(무료)
  2. 내 앱(My Apps) → 앱 만들기(Create App)
  3. 앱 유형 비즈니스(Business) → 앱 이름(예: Mirrorball-Insta) → 생성
  4. 좌측 제품 추가에서 Instagram(Instagram Graph API) 설정(Set up) 추가
  5. 앱 설정 → 기본 설정에서 앱 ID·앱 시크릿 확인 → secrets/instagram.yaml의 app_id/app_secret에 기록
⚠️ 앱 시크릿은 비밀번호급입니다. 공개·커밋 금지 (우리는 secrets/로 git 제외).

4 액세스 토큰 + 인스타 계정 ID 받기 15분

4-1. Graph API 탐색기로 단기 토큰

  1. Graph API Explorer 접속
  2. 우측 Meta App: 방금 만든 앱 선택
  3. User Token 선택 → Add Permissions에서 아래 권한 체크:
    instagram_basicinstagram_manage_insights instagram_manage_commentspages_show_list pages_read_engagementbusiness_management
  4. Generate Access Token → 로그인·동의 → 단기 토큰 생성

4-2. 인스타 비즈니스 계정 ID 찾기

# 살롱 페이지의 id(page-id) 확인
GET /me/accounts

# 그 페이지에 연결된 인스타 계정 id 확인 → 이게 ig_user_id
GET /{page-id}?fields=instagram_business_account

4-3. 단기 → 장기(60일) 토큰 교환

브라우저 주소창에 값 채워서:

https://graph.facebook.com/v23.0/oauth/access_token?grant_type=fb_exchange_token
  &client_id={app_id}&client_secret={app_secret}&fb_exchange_token={단기토큰}

→ 반환된 access_token(60일)을 secrets/instagram.yaml에 기록. 무기한이 필요하면 시스템 유저 토큰(Business Settings → System Users)으로 발급(후속).

secrets/는 git에서 제외돼 토큰이 안전해요. 템플릿만 추적됩니다.

6 연결 테스트 1분

토큰이 살아있는지 확인:

curl "https://graph.facebook.com/v23.0/{ig_user_id}?fields=username,followers_count,media_count&access_token={access_token}"

아래처럼 나오면 성공:

{"username":"salontone_...","followers_count":1234,"media_count":567}
