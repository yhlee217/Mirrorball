Research Report

담당자별 실행 리서치 보고서

각 담당자가 자기 파트를 채울 때 바로 쓰도록, 두 축(AI·로컬 노출 / 영업·카피 노하우)을 외부 리서치로 보완.

한눈에
  • AI는 "첫 40~60자의 명확한 답 + 데이터 + Q&A 구조"를 인용한다 (LLM 인용의 44.2%가 글 앞 30%에서).
  • 단골 1명 = 연 $150~250 × 4~6회, 첫방문 평균 재방문은 45%뿐 — 선예약 한 줄이 재방문을 40%→80%로.
  • 이 리서치는 우리 설계(질문형 카피·재방문 각인·번들·정직 카피·JSON-LD)를 검증했다. 빈 곳은 "실데이터".
1노하우 담당 (원장·실무자)KB·정답 카피 채우기
할 일: kb/knowledge.yaml 의 example·verified, golden_set 의 reference_output 을 검증된 실제 노하우로 교체
객단가 (업셀)
  • 번들 = 앵커링. "Color+Cut" 대신 "시그니처 컬러 트랜스포메이션" 같은 가치 네이밍 패키지로 높은 가격대에 먼저 고정.
  • "팔지 말고 진단하라." "오늘 목표가 뭐예요?" → 본드빌더·글로스/토너·두피디톡스(15분 내, 고ROI).
  • 메뉴는 판매도구: 시그니처·고수익 번들 강조, 애드온 메인 배치. 객단가 +$5~10 × 200명 = +$24k/년.
리텐션 (단골 전환)
  • 첫방문 평균 재방문 45% (Boulevard, 2,500만 예약). 첫방문자 ~70%는 안 옴. best-in-class 70%.
  • 선예약: 첫 방문에 다음을 예약한 손님 80%+ 재방문 vs "전화할게요" 40% 미만. 체어사이드 리북 +20~30%.
  • 재방문 5%↑ → 이익 25~95%↑. 단골 42%가 매출 80%. 2일 뒤 안부 문자가 신뢰.
지금 반영
KB example 을 실제 통한 멘트로 / verified 에 본인 실측치(재방문율 등)
골든 reference_output 을 본인이 쓴 5점 카피로 → 루프 기준선 상승
번들 1~2개를 가치 네이밍으로 정의해 menu/KB 반영
2콘텐츠·카피 담당AI가 인용하는 글쓰기
할 일: prompts/copy.md.j2(프로필 카피)·content.md.j2(블로그·플레이스)가 검색·AI가 인용하기 좋은 출력을 내게
AEO/GEO 인용 규칙
  • "SEO는 클릭, GEO는 인용." 검색 60%+가 클릭 없이 끝남, 44%가 AI를 1차 정보원으로.
  • 앞 40~60자에 핵심 답 — LLM 인용 44.2%가 글 앞 30%에서.
  • 150~200자마다 수치 1개(출처) — AI는 하드 데이터 우선 인용. 전문가·자격 신호는 신뢰 +41%.
  • 구조화 포맷 3배 더 인용. 질문형 헤딩·Q&A 쌍, 시맨틱 청킹(한 문단=한 개념).
우리 카피 A축(질문형+첫 문장 답)은 1순위 규칙과 일치. 추가 레버: 구체 수치·자격 신호가 아직 약함.
지금 반영
content.md.j2: "150~200자마다 사실 기반 수치 1개" 규칙 추가
블로그: 질문형 제목 + 첫 40~60자에 답 명시
자격·경력이 사실에 있으면 1회 자연 노출(과장 금지 유지)
(선택) 루브릭 A축에 "수치·자격 신호 포함" 채점 항목 추가
3노출·발행 담당 (로컬 SEO)Google & 네이버
할 일: 만든 프로필을 올리고 Google·네이버에서 실제로 노출되게 운영
Google 로컬
  • 3요소: 적합도·거리·권위. 리뷰 50개+ 안정 노출, 유지 월 5개+.
  • 사진 매주 업로드(주5장>연50장), 50장+ 순위 유리. NAP 정확 일치. 결과 4~8주~3~6개월.
네이버 (한국 시장)
  • 스마트플레이스 로직 = 적합도·인기도·신뢰도. 초기 세팅이 기초공사.
  • 사진 리뷰 100개↑ → 방문자 +115.6 / 길찾기 +79 / 저장 +55. 시술 사진 최대 300장.
  • 검색 키워드 10~15개 직접 등록(강남 헤어샵·강남역 파마…). 비포·애프터 리뷰 유도. 사업자 인증 우대.
지금 반영
GBP/플레이스 초기 세팅(카테고리·NAP 일치), 사업자 인증
리뷰 루틴: 체크아웃 요청 + 2일 후 문자 + 직링크(월 5개+)
사진 주간 업로드(전후·내부·작업), 네이버 키워드 10~15개
content.py 산출물을 블로그/플레이스 글감으로 주간 발행
4기술 담당구조화 데이터(JSON-LD)

리서치가 뒷받침하는 우선순위
