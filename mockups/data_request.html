채워주실 것만 주세요

아래만 채워주시면 빌드·루프·발행물(프로필·카드·콘텐츠·진단)은 제가 전부 만듭니다. 모르는 칸은 비워도 됩니다.

무엇을 주면 → 무엇이 나오나
주실 자료나오는 것
① 디자이너 기본 정보호스팅 프로필 페이지 + JSON-LD/SEO
② AI에 물을 질문 10개AI 노출 진단 리포트 + 경쟁 스캔
③ API 키(선택)②를 무인 자동 실행
④ 검증된 영업 노하우카피 엔진 품질↑ — "잘 파는 카피" 자동 생성
⑤ 5점 정답 카피루프의 품질 기준선 상승
⑥ 메뉴·후기·전후사진(선택)메뉴판·후기·전후 갤러리 + 손님 카드
티어 1 · 지금 당장이것만 주면 발행·진단 시작
1-A. 디자이너 기본 정보 (1명당 1개)
[ ] 안만 본인 값으로 교체. 완성 예시: 저장소 designers/minji.yaml
slug: [영문식별자 예: kimminji]

  [한두 줄 소개]

1-B. 손님이 AI에 물을 질문 10개 (진단용)

  - "[지역] [시술] 잘하는 미용실 추천해줘"
  - "[지역] [시술] 잘하는 디자이너 알려줘"
  - "[지역] 근처 [고민] 어디가 좋아"
  # ... 10개 내외
티어 2 · 진짜 무기카피 품질·노하우
2-A. 검증된 영업 노하우 3~5개 가장 가치 큼
실제로 손님 끌고 매출 낸 멘트·가격·컨설팅. example(진짜 멘트)·verified(실측 성과)가 핵심
- title: "[짧은 이름 예: 재방문 시점 각인]"
  category: "[응대전환|가격메뉴|컨설팅|SEO]"
  principle: "[카피에 녹일 한 줄 규칙]"
  applies_to:
    services: ["[적용 시술]", "또는 *"]
    signals: ["[이 상황 단어 예: 유지, 5~6개월]"]
  example: "[실제로 통했던 멘트 그대로]"
  verified: "[실측 성과 예: 재방문율 45→65%]"
2-B. 5점 "정답 카피" 1~2개
원장님이 보기에 "진짜 잘 파는 글" — 루프의 만점 기준선
case: "[예: 강남 발레아주, 뿌리·손상 걱정 고객]"
reference_copy: |
  [직접 쓴 5~7문장 카피 = 만점 기준]

티어 4 · 운영선택
API 키: GOOGLE_API_KEY 최소 1개(Gemini 무료 티어면 충분). 무인 자동 진단·콘텐츠 생성 시에만. 개발/루프 자체는 키 없이 진행 가능.
네이버/구글 플레이스 권한(있으면): 리뷰·사진·키워드 실제 반영용.
보내실 때 — 형식 그대로 텍스트로 붙여넣어 주세요(파일·표 아무거나). 최소 1-A + 1-B 한 세트면 바로 프로필 발행 + 진단을 보여드립니다. 빈 칸은 비워두셔도 진행됩니다.
